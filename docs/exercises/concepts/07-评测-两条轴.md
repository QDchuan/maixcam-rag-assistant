## 三、动手题

**H1. 用覆盖率体检一次现有报告：先跑一次 `eval`（它会落下同名的 `.md` 与 `.json`），再用 `python scripts/inspect_eval.py "eval/results/rag_L1_rag[rrf_dense+bm25].json"` 抄下生成轴那一段，然后去 json 里把所有 `items[*].generation.symbol_checked` 加起来核对，最后回答"这一行的 0.000 属于哪一种"。**

- 提示：`inspect_eval.py` 打印的"符号被检查到的题数"就是覆盖率；json 里每题一条 `items[*].generation.symbol_checked`
- 验收标准：① 报出你这份报告里"符号被检查到的题数 `k/18`"；② 报出 `symbol_checked` 之和，且与 ① 的 `k` 一致；③ 明确指出报告里同时出现的两个 0.000 里，哪一行的分母是 18（因此可以采信）、哪一行的分母是 0（因此不具参考意义）
- 依据：[tutorial 05 · §4](../../tutorial/05-评测.md) · [事故 05](../../postmortem/05-伪装成好消息的0.md) · [`scripts/inspect_eval.py`](../../../scripts/inspect_eval.py)
> 参考答案：[answers/07-评测-两条轴.md](../answers/07-评测-两条轴.md) 第 H1 题

**H2. 动手之前先写下预测：给 `Report` 加上"覆盖题数"之后，`符号级幻觉率` 那一行会显示成 `0/18` 还是 `18/18`？为什么这一行的分母不该用 18？然后动手给每条比率补上分母，再跑一次评测验证。**

- 提示：入口是 [`maixrag/evaluation/harness.py`](../../../maixrag/evaluation/harness.py) 的 `Report._agg` 与 `Report.to_markdown`；先分清每条比率的分母是"全部题"还是"被测到的题"——`_agg` 里 `with_ctx` 那个筛选条件用的是"或"
- 验收标准：① 报告里 `符号级幻觉率` 那行带上 `k/18` 形式的分母；② `recall`、`context_precision`、`citation_precision`、`citation_recall` 各自也带上分母；③ 报告里不再出现任何没有分母的比率；④ 你写下的预测与实测一致，或能说出是哪一步想错了
- 依据：[tutorial 05 · 课后习题 C1](../../tutorial/05-评测.md) · [事故 05 · C1/C2](../../postmortem/05-伪装成好消息的0.md) · [`tests/test_evaluation.py`](../../../tests/test_evaluation.py) 的 `test_run_eval_end_to_end_offline`
> 参考答案：[answers/07-评测-两条轴.md](../answers/07-评测-两条轴.md) 第 H2 题
