这九道题全部来自 MaixCAM / MaixPy 语料上的真实场景：
要么是"你会怎么做"，要么是"这个现象说明了什么"。
**没有填空题，也没有名词解释。** 卡住时看提示，做完再看答案。

## 一、概念问答（考框架 / 流程 / 算法 / 术语）

**Q1. 上下文块为什么必须带编号，而不是把片段直接拼成一段文本？**

同事提议把 Top-5 片段拼成一大段纯文本塞进 prompt——
"省掉 `[1][2]` 那些字符，模型读起来也更连贯，而且不用再教它返回 JSON"。
请说明这个改法会废掉生成层的哪几件事，并指出编号让哪些判断
从"事后字符串匹配"变成了"可程序校验"。

- 提示：想清楚"引用精确率 / 引用召回率"这两个指标各自需要什么输入才能算出来
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 Q1 题

**Q2. 幻觉率 0.000 在什么条件下是"真的很好"，在什么条件下是"几乎没测到东西"？**

评测报告里生成轴写着 `符号级幻觉率 0.000`，你正准备把它写进周报。
同一份报告里哪个数字决定你该写"防幻觉机制生效"还是"这次没测到"？
如果那个数字不理想，你下一步该去查检索轴还是生成轴？

- 提示：`hallucination_rate` 在 `symbol_checked == 0` 时返回 `0.0`——去看看这个返回值意味着什么
- 依据：[事故 05 伪装成好消息的 0](../../postmortem/05-伪装成好消息的0.md) · [concepts/07 评测：两条轴](../concepts/07-评测-两条轴.md)
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 Q2 题

**Q3. 只报"幻觉率 0.000"和同时报"拒答率 0.500"，会让技术决策差在哪一步？**

18 题的评测里，链式（L1）是幻觉率 0.000 / 拒答率 0.000，
agent 循环是幻觉率 0.000 / 拒答率 **0.500**。两栏的幻觉率一模一样。
如果只看幻觉率，你会得出"两条路线在忠实性上等价"；这个结论在哪个环节上会反过来伤到你？

- 提示：拒答率到 0.500 意味着 18 题里 9 题没有正面回答——先想"这 9 题是资料不够，还是预算用完"，再想"哪个数字能告诉你"
- 依据：[`concepts/05`](../concepts/05-生成与忠实性.md) 4.1 · [tutorial 07 端到端](../../tutorial/07-端到端.md) 第 6 节
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 Q3 题

**Q4. 三级校验阶梯为什么从"最便宜最确定的一级"开始，而不是从"最有说服力的一级"开始？**

本项目的三级是：AST + 符号存在性（第一级）→ 签名/参数校验（第二级）→ 真实执行（真机或 mock shim，第三级）。
假设你手上只有一台真机 MaixCAM、组里还没有任何人搭过 `maix` shim，
你要怎么安排这三级的落地顺序与投入？说清每一级的代价。

- 提示：先分别列出三级的"成本"和"能抓住哪一类错误"，再回答"哪一级值得先做"
- 依据：[design 01 · 4.5.3 输出校验](../../design/01-系统架构设计.md)
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 Q4 题

## 二、工程问答（考局限性 / 选型 / 取舍 / 边界）

**Q5. 幻觉率与拒答率在同一个旋钮上——什么时候你宁可让它拒答，什么时候宁可让它硬答？**

同一个 18 题的评测集，你只有一次配置机会，调完就要交付。
往保守调，幻觉率会降、拒答率会涨；往激进调则相反。
请给出你的判断依据，并说明这个取舍在什么条件下会失效。

- 提示：先给题目分类（哪几类题答错的代价最高），再想"拒答"和"编造"在这几类题上各值多少钱
- 依据：[`concepts/05`](../concepts/05-生成与忠实性.md) 4.1 与误解二 · [`eval/results/agent_loop.md`](../../../eval/results/agent_loop.md) · [`eval/results/rag_L1_rag[rrf_dense+bm25].md`](<../../../eval/results/rag_L1_rag[rrf_dense+bm25].md>)
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 Q5 题

**Q6. 什么时候必须上第一级校验（硬阻断），什么时候只该警告或记录？**

项目里的三级校验，失败处理是逐级放宽的：第一级阻断、第二级警告并标注、第三级只记录。
现在有一类新错误：`camera.Camera()` 的参数顺序写错了（符号全部存在）。
它该落在哪一级？为什么**不能**在第一级硬阻断它？
再反过来问：什么条件下你才会允许第一级真的把答案拦下来并拒答？

- 提示：决定"能不能硬阻断"的不是错误有多严重，而是**这个信号有多确定、误报率有多低**
- 依据：[design 01 · 4.5.3](../../design/01-系统架构设计.md) · [事故 03 校验器把正确代码判成幻觉](../../postmortem/03-校验器把正确代码判成幻觉.md)
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 Q6 题

**Q7. 第一级校验误报了，你必须先看哪里？（无唯一答案）**

团队在 MaixPy 例程上跑第一级校验，日志里出现：
`maix.gpio.GPIO`、`maix.gpio.Mode.OUT` 被判成"不存在的符号"。
但写这段代码的人用的是官方推荐写法 `from maix import gpio`，代码是对的。

请给出你的排查与处置方案：先怀疑什么、怎么确认、以及除了"修白名单"之外
你还必须一起改掉什么，否则同一个坑会以另一种形式回来。

- 提示：白名单是从哪里生成的？"文档里的模块路径"和"用户实际 import 的路径"是同一个东西吗？
- 依据：[事故 03](../../postmortem/03-校验器把正确代码判成幻觉.md) · [tutorial 01 · 第 6 节第三点](../../tutorial/01-失败是什么样的.md)
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 Q7 题

## 三、动手题

**H1. 先把符号校验器跑一遍，再去看真实评测的覆盖面。**

两件事连着做：

1. 把校验前后要发生的事先写下来，再跑 `python scripts/check_symbols_demo.py`；
2. 用 `python scripts/inspect_eval.py "eval/results/agent_loop.json"` 打开仓库里已有的 agent 评测报告，
   读出"符号被检查到的题数"是几分之几。

然后回答：这份报告里的 `符号级幻觉率 0.000`，到底能不能读成"agent 不编 API"？

- 提示：第 2 步只读已有 JSON，不会覆盖任何报告；先看清分母，再解读分子
- 依据：[concepts/05 · 第 7 节动手题](../concepts/05-生成与忠实性.md) · [`scripts/inspect_eval.py`](../../../scripts/inspect_eval.py)
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 H1 题

**H2. 把"会犯错的假模型"关掉，看第一级校验会失去什么。**

这是一道改造题，**动手之前必须先把预测写下来**。

先跑一次（它会让假模型在"没有资料"时编一个不存在的 API）：

```powershell
$env:CHAT_MODEL = "fake"
python -m maixrag --config configs/l0_no_rag.yaml ask "MaixCAM 上怎么把一张图放大两倍？" --level no_rag
```

再照 [tutorial 01 · C1](../../tutorial/01-失败是什么样的.md) 的写法，构造 `FakeChat(hallucinate_on_miss=False)`
跑同一句话，比较两次输出。

- 提示：关掉之后编译器/校验器那一级还剩下什么可测的东西？这个假模型是给谁准备"靶子"的？
- 验收：预测与实测一致；若不一致，能指出你漏考虑了哪一步，并说出第一级校验在这两次运行里**各检查了几个符号**
- 依据：[tutorial 01 · C1](../../tutorial/01-失败是什么样的.md) · [`maixrag/providers.py`](../../../maixrag/providers.py) · [`concepts/05`](../concepts/05-生成与忠实性.md) 误解一
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 H2 题

**H3. 给"覆盖面"造一次现场：让同一个 0.000 的两种含义同时出现。**

同一条命令、同一份评测集，只换一个开关：

```powershell
python -m maixrag --config configs/l2_hybrid.yaml eval --level rag --fake-chat
python scripts/inspect_eval.py "eval/results/rag_L1_rag[rrf_dense+bm25].json"
```

1. 先记下这次跑出来的分组表（四行 `qtype` 的 Recall@K）；
2. 用 `python scripts/inspect_eval.py` 读出这次跑的**符号被检查到的题数**；
3. 回答一个问题：这一次的 `符号级幻觉率 0.000`，和"模型真的一个 API 都没编"是不是同一件事？

- 提示：`--fake-chat` 换来的是 `NoopChat`，它返回空答案——先想"没有代码，还有符号可查吗"
- 验收：① 能说出这次跑的符号覆盖面是几分之几，并解释为什么；② 能说出为什么 `--fake-chat` 那次的**检索轴**数字仍然可以看，而**生成轴**数字不能看
- 依据：[tutorial 05 · 第 4 节](../../tutorial/05-评测.md) · [postmortem 05 · 修复](../../postmortem/05-伪装成好消息的0.md) · [`maixrag/builders.py`](../../../maixrag/builders.py) 的 `NoopChat`
> 参考答案：[answers/05-生成与忠实性.md](../answers/05-生成与忠实性.md) 第 H3 题
