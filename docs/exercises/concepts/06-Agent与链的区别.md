# 习题 · Agent 与链的区别

> 对应概念文档：[concepts/06-Agent与链的区别.md](../concepts/06-Agent与链的区别.md)
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md)　← **先自己想，再看答案**

九道题：概念问答 4 道、工程问答 3 道、动手题 2 道。
工程题里有一道**没有唯一正确答案**，它的验收标准是"你的答案里有没有代价分析和失效条件"。

## 一、概念问答（考框架 / 流程 / 算法 / 术语）

**Q1. 团队要写一页"链与循环的选型说明"。请把这一个区别说清楚——用"每一步的决策由谁做"这个角度，逐步说一遍链和循环各是谁在拍板。然后回答：为什么由此多出来的四类问题（可插拔 / 可描述 / 可停止 / 可约束）不能靠"换一个更强的模型"解决？**

- 提示：先问"这一跳走哪条路、走几步，是谁定的"；再逐个问那四件事——哪一件是模型能力范畴，哪一件是系统边界范畴
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 Q1 题

**Q2. 试点要上线，评审要求"三条预算线只留一条，把配置摊平"。如果只允许你保留一条，你保留哪条？你放弃的那两条，分别让你暴露在什么失效下？**

- 提示：先分别想清三条线各自防谁、失效时是**显式失败**还是**无声失败**；再想在你的场景里，哪种失效的代价更大
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 Q2 题

**Q3. 值班时你收到一条告警：agent 在"为什么我的摄像头读不到图像"这类多跳问题上连续失败。你要判断这是"预算不够"还是"方法不行"。给出可操作的判据——不是"多试几次"，而是"我打开哪个文件、看哪几样东西、看到什么就下哪个结论"。**

- 提示：agent 的轨迹是结构化事件流不是日志；另外，一次运行的资源消耗和最终指标是两样东西
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 Q3 题

**Q4. 链式的成本是固定的，循环的成本是不确定的。这一条对「评测设计」意味着什么？说出评测器为了这件事必须多产出哪些东西，以及为什么只报告指标分数在这一章里是不够的。**

- 提示：回到这一章开头那句"下游要能判断这次值不值"；再想一件事——两份报告数字可直接对比的前提是什么
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 Q4 题

## 二、工程问答（考局限性 / 选型 / 取舍 / 边界）

**Q5. 客户提了一类问题："`maix.camera.Camera.read()` 的参数是什么？"你要向团队解释：这一类问题不该交给 agent 去做。请给出带代价分析的论证，并说明在什么条件下你的这个判断会翻转。**

- 提示：把这一类问题与"MaixPy 里怎么做 YOLO 物体检测？给出完整例程"放在一起比；如果你手上没有成本数据，"不该"就只是一个主张
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 Q5 题

**Q6.（无唯一答案的取舍题）YOLO 例程那道题上一轮跑失败了，团队里两种声音：一方说"把 `max_turns` 从 10 提到 20，加钱就能过"；另一方说"agent 不适合这类题，砍掉"。你是技术负责人，给一个判断依据，并说明你会怎么用它来裁决。**

- 提示：先分清"我没做完"（显式失败）和"每次都成功、只是没有进展"（无声失败）——它们对应的修法相反；然后想：你要看哪一份材料才敢下结论
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 Q6 题

**Q7. 团队要写一条"预算给多少才够"的判据，不能靠拍脑袋。请用 18 题的评测结果给出这条判据：看哪个数字、和什么比、比值落在哪里代表"够"、落在哪里代表"该调"，并且要能说清它在什么情况下会误导你。**

- 提示：`--max-turns` 不是唯一的那个上限；先去看命令行代码里预算的默认装配，把"上限"这个分母找对；再想分子是什么（轮次还是工具调用）
> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 Q7 题

## 三、动手题

**H1. 用同一个假模型、同一道 YOLO 题，把轮次预算分别设成 1 和 3 各跑一次，比较两次输出的"结束原因"和答案形态；然后说出：要复现"agent 比链式还差"这件事，为什么必须换真实对话模型。**

在动手之前，先把预测写下来（两次的结束原因分别是什么、答案分别长什么样）。

```bash
python -m maixrag --config configs/l2_hybrid.yaml agent "MaixPy 里怎么做 YOLO 物体检测？给出完整例程" --fake-chat --max-turns 1
python -m maixrag --config configs/l2_hybrid.yaml agent "MaixPy 里怎么做 YOLO 物体检测？给出完整例程" --fake-chat --max-turns 3
```

- 提示：1 轮预算下，第 1 轮只够做一件事，而循环需要再来一轮才能收口；注意你看到的是"降级"还是"异常"
- **验收标准**：两次运行的【执行轨迹】末尾"结束原因 / 消耗"与你事先写的预测一致；1 轮那次【答案】里出现"未能完成回答"和一个具体的耗尽原因（不是空文本），并且你能指出这是优雅降级而不是抛异常；最后能说出假模型为什么复现不出"agent 比链式还差"
- 依据：[tutorial 06 · 4 与 6.4](../../tutorial/06-Agent-五块机制.md)、[事故 06 · 怎么发现的](../../postmortem/06-预算与任务不匹配.md)、`maixrag/agent/loop.py`

> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 H1 题

**H2. 给评测报告加一个"预算使用率"指标（平均消耗 ÷ 上限）。在当前 18 题的结果上，它落在哪里？多少算"该调大"？之后回答一个问题：如果只想看一个字段来判断"预算对不对"，你加哪个，为什么它比最终指标更有用？**

- 提示：先看 `maixrag/cli.py` 里预算的装配方式和 `_avg_tool_calls` 是怎么读计数的；注意"平均每题工具调用"和"轮次"不是同一个量，上限也不是 `max_turns` 那一个数
- **验收标准**：写出你算出的使用率（含分子、分母、来源命令），给出一个阈值并说明为什么是这个数；并且能指出，报告里哪一格数据在**假模型**下会假到让你误判（它具体可能是多少）
- 依据：[事故 06 · 修复](../../postmortem/06-预算与任务不匹配.md)、[tutorial 06 · 6.4](../../tutorial/06-Agent-五块机制.md)、[eval/results/agent_loop.md](<../../../eval/results/agent_loop.md>)、`maixrag/cli.py` 的 `_avg_tool_calls`

> 参考答案：[answers/06-Agent与链的区别.md](../answers/06-Agent与链的区别.md) 第 H2 题
